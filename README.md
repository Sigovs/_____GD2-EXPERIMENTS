# _____GD2-EXPERIMENTS

Публикуемая раскладка рабочего каталога `GD 2 AAN`. Шесть лабораторий,
тридцать версий. **Папка на лабораторию, подпапка на каждую версию.**

```
/                       корневая полка — все тридцать версий одной страницей
  previews/             превью, имя файла = slug из tools/versions.json
  _shelf/               токены и CSS полки (взяты из aan test 4)
  index1_1/             версия = папка
  aan test N/
    index.html          полка лаборатории
    <версия>/index.html
    <общие ассеты>      один раз на лабораторию, не в каждой версии
```

## Почему ассеты не лежат в каждой подпапке

`assets20` весит 35 МБ и нужен одиннадцати версиям `aan test 4`. Положить его в
каждую подпапку — 385 МБ вместо 35 и ни одного выигрыша. Ассеты остаются на
уровне лаборатории, а пути внутри страницы сдвинуты на один уровень вверх.

## Что где

| папка | версий | как устроено |
|---|---|---|
| `index1_1/` | 1 | один самодостаточный файл, открывается откуда угодно |
| `aan test 1/` | 9 | одна сборка Vite в `_app/`, подпапка версии ведёт на свой режим |
| `aan test 2/` | 2 | статика |
| `aan test 3/` | 1 | скаффолд Vite как есть — не собран, не запускается |
| `aan test 4/` | 11 | статика |
| `aan test 5/` | 4 | статика |
| `aan test 6/` | 2 | только запись: зеркало не выложено |

### aan test 1 — почему подпапка, а не девять сборок

Девять «версий» — это один вход, читающий query-параметр. Девять сборок значили
бы девять копий одних и тех же 95 МБ моделей. Собрано один раз в `_app/`; папка
версии — её адрес, а не её копия. Корневые пути (`/models/…`) в собранных чанках
сняты до относительных, иначе на Pages они уходят в корень домена.

### aan test 6 — почему зеркала здесь нет

Две независимые причины. Технически: зеркало держит корневые пути (`/_astro/…`)
и работает только в корне сервера — в подпапке репозитория оно не резолвится, а
переписать 33 страницы значит перестать быть зеркалом 1:1. По существу: это
полная копия чужого коммерческого сайта, и держать её локально для разбора — не
то же самое, что выложить публично. Папки версий на месте, в них запись и превью.

## Пересборка

Дерево собирается целиком, руками ничего не правится:

```
cd "c:/____WORK/_____GD 2 AAN/aan test 1" && npx vite build --base ./
cd "c:/____WORK/_____GD2-EXPERIMENTS"     && node tools/build.mjs
```

Что версия **есть** и что она **решает** — берётся из `tools/versions.json`, а он
называет источник каждой строки. Ни одна строка карточки не написана по памяти.
